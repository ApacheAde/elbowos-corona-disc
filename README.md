# Corona Disc

Full-colour Python 3 neon **disc-canyon** arcade for [ElbowOS](https://x.com/ElbowOS).

Bank a gold corona disc through lime / amber / magenta rings.
Magenta wind ribbons shove the flight. Violet canyon pillars clip the combo.
`A` / `D` (or arrows) curve mid-air. `Space` relaunches. `R` resets.

## Play

```bash
pip install -r requirements.txt
python3 corona_disc.py --play
```

## Record a 9:16 reel

```bash
SDL_VIDEODRIVER=dummy python3 corona_disc.py
```

Writes a 15s 1080×1920 H.264 MP4 (title + score + `x.com/ElbowOS` burned in).
